# 🐉 RPG de Combate em Python

Um jogo de RPG baseado em turnos desenvolvido em Python, onde o jogador cria um personagem e enfrenta inimigos em batalhas dinâmicas inspiradas em RPGs de mesa.

O projeto utiliza mecânicas de rolagem de dados e conceitos de Programação Orientada a Objetos para simular combates estratégicos e imprevisíveis.

---

## 🎮 Funcionalidades

- 🧙 Criação de personagem com nome, raça e classe (Guerreiro, Mago ou Ladrão)  
- ⚔️ Sistema de combate por turnos (jogador vs inimigo)  
- 🎲 Mecânica de dados (ex: 1d20 para acerto, 2d6 para dano)  
- 💥 Sistema de acerto, erro e acerto crítico  
- 👾 Inimigos gerados aleatoriamente com atributos únicos  
- ⏳ Mensagens imersivas com delays para simular o ritmo de combate  

---

## 🧠 Conceitos aplicados

Este projeto foi desenvolvido com foco em conceitos fundamentais de programação:

- Programação Orientada a Objetos (POO)
  - Herança
  - Polimorfismo
- Estrutura de classes e objetos
- Lógica de controle de fluxo
- Simulação com aleatoriedade

---

## 🛠️ Tecnologias utilizadas

- Python  
- Módulo `random` (geração de números aleatórios)  
- Módulo `time` (controle de tempo e delays)
