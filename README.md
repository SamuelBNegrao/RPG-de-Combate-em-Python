# 🐉 RPG de Combate em Python

Um jogo simples de RPG em Python onde o jogador cria um personagem e enfrenta inimigos em batalhas por turnos com mecânicas baseadas em rolagem de dados.

---

## 🎮 Funcionalidades

- 🧙 Criação de personagem com nome, raça e classe (Guerreiro, Mago ou Ladrão)  
- ⚔️ Sistema de combate por turnos  
- 🎲 Ataques e acertos baseados em rolagem de dados  
- 👾 Inimigos aleatórios com atributos únicos (vida, armadura e dano)  
- ⏳ Mensagens imersivas com delays para simular o ritmo de combate  

---

## 🛠️ Tecnologias utilizadas

- Python  
- Programação Orientada a Objetos (POO)  
- Módulo `random`  
- Módulo `time`  

---
